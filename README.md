
# Multiplication Table Generator

A beginner-friendly Python project that generates
multiplication tables from 2 to 20.

## Features

- Generates tables from 2 to 20.
- Each table contains multiples from 1 to 10.
- Saves each table in a separate text file.
- Creates the output directory automatically.

## Requirements

- Python 3.14.6 

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run:

   ```bash
   python main.py
   ```
